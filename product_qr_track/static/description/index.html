How it works

Three steps, start to finish — no extra setup per product.

1 Print the QR label

From the product, open Print Labels and pick the QR format — it's auto-generated per variant.

2 Customer scans

The code opens a trackable link straight to that product's page on your website.

3 You see the visit

Every scan is logged automatically — country, OS, browser, GeoIP and product, right in Odoo.

Frequently asked questions

Does this app work with Odoo Enterprise and Community?

Yes — it works with both Odoo Enterprise (on-premise and Odoo.sh) and Community. Odoo Online (cloud) does not allow installing third-party apps, so this module can't be installed there.
